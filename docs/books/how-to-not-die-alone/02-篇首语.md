# 篇首语

说到学术研究，这里有个坏消息：到目前为止，大多数婚恋研究针对的都是顺性别的异性恋情侣。不过万幸的是，科研人员研究了性少数群体[1]之后发现，他们在亲密关系上遇到的问题和异性恋遇到的问题大同小异，所以，性少数群体同样能从现有的研究中获益。

在写这本书的过程中，我采访了不同性取向和性身份的人。我也会向大家分享性少数群体的爱情故事和恋爱体验。本书讲到的所有故事都是真实的，不过，书中有几个人物的经历是由几个人的故事组合而成的。我在书中适当修改了名字和身份特征，并且重新加工了采访对话。

本书脱稿后，我接受了一家手机应用软件“Hinge”公司的工作邀约，担任婚恋关系科学总监。这个职位让我有机会帮助数百万人学习如何更有效地谈恋爱。本书中所有的研究和观点均出自我本人。

[1] 性少数群体（LGBTQ+）分别指代：L（Lesbian），女同性恋；G（Gay），男同性恋；B（Bisexual），双性恋；T（Transgender），跨性别者；Q（Queer）酷儿，包括了所有在性倾向方面与主流文化和占统治地位的社会性别规范或性规范不符的人；“＋”号在这里表示“等等”。——译者注
